⚡ Critical Analyst Notes
  • Not flagged ≠ safe. VirusTotal clean does not mean benign — new/targeted attacks are unknown to vendors. Assume suspicious.
  • Compromised domains pass SPF/DKIM. A legitimate domain's authentication can pass even if attacker controls the sending mailbox.
  • BEC critical artifact is Reply-To. The From address looks legitimate; the attacker's address hides in Reply-To.
  • Always analyze in a VM. Never open attachments or click links on a production system.
📝 Report Writing: Defang All IOCs
  • IP addresses: 8.8.8.8 → 8[.]8[.]8[.]8
  • URLs: https://evil.com → hxxps://evil[.]com
  • Use CyberChef → Defang IP / Defang URL for batch processing
  • Every block action must log: Block Type · Value · Date/Time · Analyst Name
  • Always document your justification and assess negative business impact before blocking.
🛡 Blocking Decision Reference
  • Sender Address → Email Gateway block (if uniquely malicious)
  • Sender Domain → Email Gateway (only if entirely malicious)
  • Sending Server IP → Email Gateway (avoid if shared/legit provider)
  • Subject Line → Email Gateway (if highly specific & unlikely to match legit mail)
  • Malicious URL / Domain → Web Proxy block
  • File Hash → AV / EDR / Endpoint block
